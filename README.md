## Обо мне

Я Frontend-разработчик с `3+ годами коммерческого опыта` в создании современных web-приложений.

Основной стек – `React`, `Next.js`, `TypeScript` и современная frontend-экосистема. Работаю с клиентским и серверным рендерингом, интеграцией API, состоянием приложения, формами, real-time функциональностью и адаптивной версткой.

Мне важно писать понятный, поддерживаемый код и создавать интерфейсы, которые не только хорошо выглядят, но и удобно работают для пользователя.

## Основная специализация

- Frontend-разработка на `React`, `Next.js` и `TypeScript`
- Коммерческий опыт разработки web-приложений: `3+ года`
- Работа с `SSR`, `SSG`, routing, layouts и оптимизацией страниц
- Интеграция REST API, обработка ошибок и работа с асинхронными данными
- Real-time функциональность через `WebSocket`
- Управление состоянием через `Redux Toolkit`, `Zustand`
- Работа с серверным состоянием через `TanStack Query`
- Формы и валидация: `React Hook Form`, `Zod`
- UI-разработка с `Material UI`, `Ant Design`, `Tailwind CSS`, `Sass`
- Анимации и интерактивность через `Framer Motion`
- Поддержка качества кода: `ESLint`, `Prettier`, архитектура компонентов
